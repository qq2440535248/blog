# Person Blog

前后端分离个人博客项目（Vue3 + Express）。

## 技术栈

- 前端：Vue 3, Vite, Vue Router, Pinia, Element Plus, Axios, Markdown-it, Highlight.js
- 后端：Node.js, Express, Sequelize, MySQL, JWT, bcrypt
- 包管理：pnpm

## 目录结构

- `frontend`: 前端项目
- `backend`: 后端项目

## 快速开始

```bash
pnpm install
pnpm dev:frontend
pnpm dev:backend
```
